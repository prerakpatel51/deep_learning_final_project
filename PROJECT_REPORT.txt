1. PROJECT OVERVIEW
================================================================================

This project implements a comprehensive deep learning solution for automated
skin lesion classification using Convolutional Neural Networks (CNNs). The
system classifies skin lesions into 7 different categories to assist in early
detection and diagnosis of skin cancer and other dermatological conditions.

Problem Statement:
Skin cancer is one of the most common cancers worldwide. Early detection
significantly improves treatment outcomes. This project aims to develop an
automated classification system to assist dermatologists in identifying
different types of skin lesions from images.


================================================================================
2. DATASET
================================================================================

Dataset Source: HAM10000 (Human Against Machine with 10000 training images)
- Kaggle Dataset: "farjanakabirsamanta/skin-cancer-dataset"
- Total Images: 10,015 dermatoscopic images
- Image Format: JPG/JPEG
- Resolution: Variable (resized to 360x360 for training)

Class Distribution (7 Classes):
1. Nevus (nv) - Melanocytic nevi (moles)
2. Melanoma (mel) - Malignant melanoma
3. Benign keratosis (bkl) - Benign keratosis-like lesions
4. Basal cell carcinoma (bcc) - Basal cell carcinoma
5. Actinic keratosis (akiec) - Actinic keratoses and intraepithelial carcinoma
6. Vascular lesions (vasc) - Vascular lesions
7. Dermatofibroma (df) - Dermatofibroma

Dataset Challenges:
- Severe class imbalance (Nevus: ~6700 images, Dermatofibroma: ~115 images)
- Visual similarity between different lesion types
- Variable image quality and lighting conditions
- Artifacts (hair, rulers, markers) in some images

Data Split:
- Training Set: 80%
- Validation Set: 10%
- Test Set: 10%
(Stratified splits to maintain class distribution)


================================================================================
3. DATA PREPROCESSING & AUGMENTATION
================================================================================

3.1 Data Organization
--------------------
- Downloaded via Kagglehub API
- Organized into train/val/test directories
- Structured using metadata CSV for class mapping
- Reproducible splits using seed=42

3.2 Class Balancing Strategy
---------------------------
Implemented custom BalancedDataset class with target of 400 samples per class:

- Oversampling: Classes with < 400 images were augmented through random
  sampling with replacement
- Undersampling: Classes with > 400 images were randomly subsampled
- Result: Balanced training set with 2800 total images (400 per class)

3.3 Image Preprocessing
-----------------------
Image Size: Resized to 360x360 pixels
Normalization: ImageNet statistics
  - Mean: [0.485, 0.456, 0.406]
  - Std: [0.229, 0.224, 0.225]

3.4 Data Augmentation (Training Only)
------------------------------------
Applied real-time augmentation to improve model generalization:
- Random Horizontal Flip
- Random Vertical Flip
- Random Rotation (up to 20 degrees)
- Color Jitter (brightness, contrast, saturation, hue adjustments by 0.1)

Validation/Test: Only resizing and normalization (no augmentation)


================================================================================
4. METHODOLOGY
================================================================================

4.1 Model Architectures
----------------------
Two popular CNN architectures were evaluated:

A. ResNet50 (Residual Network)
   - 50 layers deep with residual connections
   - Advantages: Addresses vanishing gradient problem
   - Parameters: ~25.6M
   - Modified final layer for 7-class classification

B. VGG16 (Visual Geometry Group)
   - 16 layers with simple architecture
   - Advantages: Strong feature extraction capabilities
   - Parameters: ~138M
   - Modified classifier for 7-class classification

4.2 Transfer Learning vs Training from Scratch
----------------------------------------------
Each architecture was tested in two modes:
1. Pretrained: Using ImageNet pretrained weights (transfer learning)
2. From Scratch: Random weight initialization

Total Models Tested: 4 base models (2 architectures x 2 initialization modes)

4.3 Model Modifications
----------------------
Both architectures were modified for the 7-class classification task:
- ResNet50: Replaced final FC layer with Dropout + Linear(2048 -> 7)
- VGG16: Replaced final classifier layer with Dropout + Linear(4096 -> 7)
- Dropout rates: Varied per configuration (0.3, 0.5, 0.7)

4.4 Training Procedure
---------------------
Loss Function: Cross-Entropy Loss
Optimization: Adam and RMSprop optimizers tested
Learning Rate Schedule: Fixed learning rate per configuration
Early Stopping: Patience of 10 epochs (validation accuracy)
Maximum Epochs: 50

Training Features:
- GPU acceleration with CUDA
- Multi-GPU support via DataParallel
- Checkpointing (saves best model based on validation accuracy)
- Comprehensive logging of training/validation metrics
- Reproducibility through random seed control

2. ResNet50 vs VGG16: ResNet50 generally achieved better F1 scores and more

3. Learning Rate Impact: Lower learning rates (1e-4, 1e-5) with pretrained
   models worked better than higher rates (1e-3).

4. From-Scratch Performance: Models trained from scratch showed poor
   performance, especially VGG16, indicating the dataset size is insufficient
   for training these complex architectures without transfer learning.

5. High ROC-AUC Scores: All pretrained models achieved ROC-AUC > 0.92,
   indicating excellent discriminative ability across classes.

8. CONCLUSIONS
================================================================================

8.1 Project Achievements
-----------------------
1. Successfully implemented and compared multiple CNN architectures for
   automated skin lesion classification

2. Achieved strong performance with best model reaching:
   - 76.95% accuracy
   - 0.698 macro F1 score
   - 0.958 ROC-AUC
   on a challenging 7-class imbalanced dataset

3. Demonstrated the critical importance of transfer learning for medical
   image classification with limited data

4. Developed a comprehensive experimental framework testing 16 different
   model configurations systematically

5. Created extensive visualizations for model interpretation and analysis

6. Implemented effective data balancing strategies to handle severe class
   imbalance

8.2 Key Findings
---------------
1. Transfer learning is essential: Pretrained models vastly outperformed
   models trained from scratch, showing the value of ImageNet pretraining
   even for medical images.

2. ResNet architecture superiority: ResNet50 generally provided better
   balanced performance compared to VGG16, likely due to residual connections
   enabling better gradient flow.

3. Hyperparameter importance: Moderate dropout (0.5), lower learning rate
   (1e-4), and appropriate weight decay (1e-2) proved most effective.

4. Data augmentation value: Real-time augmentation helped improve
   generalization without explicitly measuring the isolated impact.

5. Class imbalance challenge: Despite balancing, minority classes remained
   more challenging, suggesting the need for more sophisticated techniques.

8.3 Limitations
--------------
1. Dataset size: 10,000 images is relatively small for training deep networks
   from scratch

2. Class imbalance: Original severe imbalance may still impact feature
   learning despite balancing techniques

3. Single dataset: Results specific to HAM10000; generalization to other
   sources unknown

4. Limited architecture exploration: Only tested ResNet50 and VGG16; other
   architectures (EfficientNet, Vision Transformers) not explored

5. No ensemble methods: Single model predictions; ensembles could improve
   performance

6. Hyperparameter search: Grid search over limited configurations; more
   sophisticated optimization (Bayesian, random search) could improve results

8.4 Real-World Applicability
---------------------------
The best model (76.95% accuracy, 0.698 F1) shows promise as a screening tool
to assist dermatologists, but performance gaps exist:

Strengths:
- Excellent ROC-AUC (0.958) indicates strong discriminative ability
- Good performance on common lesion types (Nevus, Melanoma)
- Fast inference for real-time screening

Areas for Improvement:
- Performance on rare lesion types needs enhancement
- Clinical deployment requires higher accuracy standards
- Explainability/interpretability crucial for medical applications
